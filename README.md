# 더 커뮤니티 2 팬메이드 게임

웨이브(Wavve)의 〈더 커뮤니티2: 보이지 않는 손〉에 등장하는 게임으로 만든 비공식 팬메이드 웹 게임 모음입니다.

## 구성
| 경로 | 내용 |
|---|---|
| `index.html` | 메인 화면 — 게임 선택 |
| `fact-hopscotch/` | 팩트 땅따먹기 — `index.html`(게임), `questions.js`(문제 DB, 키워드별 1,000문항, 형식: `[문제, 정답(1=O, 0=X), 해설]`) |
| `proposition-race/` | 명제 레이스 — `index.html`(게임), `data.js`(국가별 지표·출처, 자물쇠 상자 문제 DB), `sfx.js`(카운트다운·사이렌 효과음) |

각 게임 첫 화면 왼쪽 위의 `← 게임 선택`으로 메인 화면에 돌아갈 수 있습니다.

## 로컬 실행
`index.html`을 브라우저로 열면 됩니다. 게임 폴더의 `index.html`을 직접 열어도 각각 실행됩니다.

## 배포
정적 사이트입니다. 빌드 과정 없이 저장소 루트를 그대로 배포합니다.
- 메인: `/`
- 팩트 땅따먹기: `/fact-hopscotch/`
- 명제 레이스: `/proposition-race/`

## 명제 레이스 데이터 출처
세계은행(GDP·인구·가계지출·인구밀도·국토면적·PPP·경상수지·기대수명·실업률), WHO(자살률·비만율), ITU(인터넷이용률), 국제투명성기구(부패인식지수), 국경없는기자회(언론자유지수), IMD(세계경쟁력순위), UNDP(성불평등지수).
